# docker-agent-sandbox

A hardened, lightweight Alpine-based container environment designed specifically for evaluating and running untrusted LLM code generated by autonomous agents.

## Security Controls

- **Unprivileged Execution**: Drops privileges to `sandboxuser` (`UID 1000`).
- **Minimal Surface**: Alpine 3.20 base with standard Python 3 and Node.js runtimes.
- **Zombie Process Reaping**: Uses `tini` as init process.

## Usage

```bash
docker build -t docker-agent-sandbox .
docker run --rm -it --network none --memory 512m --cpus 1.0 docker-agent-sandbox
```
